# 魔搭社区赛道交付说明

> 赛题：魔搭社区（20 分）｜提交物：**自己编写的 Skill 在魔搭社区上的网址或编号**

## 1. 交付的 Skill

| 项 | 值 |
|---|---|
| 名称 | `db-memory-recall` |
| 用途 | 把数据库排查的结论沉淀成可召回的记忆，并区分「历史记忆」与「本次实测」 |
| 目录 | `db-memory-recall/SKILL.md`（单文件 Skill，可直接上传） |

内容概要：

1. **先召回再动手** —— 拿到问题先在目标 scope 里检索记忆，命中后先判断结论是否仍然适用；
2. **实地核实** —— 记忆只当线索，要落地必须在当前 seekdb 实例上用 `SHOW CREATE TABLE` /
   `EXPLAIN` / 真实数据验证；
3. **结论写回** —— 把「现象 / 根因 / 证据 / 处置 / 适用范围」写成一条可复用的记忆；
4. **回答时区分来源** —— 明确标注哪些是历史记忆、哪些是本次实测；没有依据的信息写「未核实」。

它同时用到本次大赛的两项指定能力：seekdb（读真实结构与执行计划）与
PowerContext（记忆的写入与召回）。

## 2. 上传步骤（需要你在魔搭社区账号下操作）

1. 登录魔搭社区，进入「Skill」上传入口；
2. 把 `db-memory-recall/SKILL.md` 作为 Skill 文件上传（该 Skill 无需脚本与依赖，
   单个 SKILL.md 即可运行）；
3. 上传后打开自己的 Skill 页面，确认内容可查看；
4. 复制该 Skill 的**完整页面网址**或**编号**；
5. 登录大赛测评平台，进入「魔搭社区赛题」的提交入口，把上面的网址或编号填入提交。
